# Domains the DNSSEC survey asks about, one per line.
#
# The point of the survey is false failures: neither the unit tests nor the
# integration suite can show that validation leaves working names working,
# because both answer from fixtures. So this asks real names through elodin and
# asks a reference validating resolver the same thing, and compares both the
# rcode and the AD bit.
#
# A name marked `bogus` is deliberately broken and must be refused. Everything
# else must resolve, and should agree with the reference on whether it was
# authenticated.
